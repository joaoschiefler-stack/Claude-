**Início:** 2026-04-28 | **Meta:** Demo funcionando + 1º cliente em negociação

## Semana 1 (28 abr – 4 mai) — Construir o Demo

**Objetivo:** Ter um voice agent funcionando em PT-BR antes de falar com qualquer dentista.

- [ ] Criar conta Retell AI (trial gratuito) em retellai.com
- [ ] Criar conta Twilio (trial ~R$30 de crédito gratuito) — pegar número BR +55
- [ ] Configurar voice agent "Clínica Odontológica Exemplo" com script base:
  - Cumprimento ("Clínica [Nome], boa tarde, como posso ajudar?")
  - Respostas: horários, endereço, procedimentos comuns, planos aceitos
  - Coleta de agendamento: nome + procedimento + horário preferido
  - Transferência para humano: ao ouvir "urgência", "dor forte", "emergência"
- [ ] Ligar 20x para o número com diferentes pedidos e sotaques
- [ ] Pedir para 3 pessoas de confiança ligarem e darem feedback
- [ ] **Critério para avançar:** ≥ 80% das ligações sem erro grave

## Semana 2 (5–11 mai) — Demo Pronto, Início da Prospecção

**Objetivo:** Gravar o vídeo demo e enviar as primeiras 100 DMs.

- [x] Gravar vídeo de 60s mostrando ligação real para o demo (tela do celular + áudio)
- [ ] Editar no CapCut — legendar em português (opcional mas recomendado)
- [ ] Montar lista de 100 dentistas no Instagram: buscar "dentista joinville", "dentista [bairro]", verificar se tem telefone ou WhatsApp no perfil
- [ ] Enviar 15–20 DMs/dia com mensagem personalizada (ver scripts em `cold-outreach-playbook.md`)
- [ ] Registrar numa planilha simples: enviado / lido / respondeu / pediu demo / desinteressado
- [ ] **Critério para avançar:** pelo menos 5 respostas em 100 DMs

## Semana 3 (12–18 mai) — Qualificar Interessados

**Objetivo:** Converter respostas em conversas de demo ao vivo.

- [ ] Para cada resposta positiva: enviar o vídeo demo de 60s
- [ ] Se pedirem mais informações: fazer chamada de 10 min (WhatsApp ou Google Meet)
  - Perguntar: volume de ligações/dia, tem recepcionista hoje, principal problema
  - Calcular custo estimado de plataforma durante a call
  - Apresentar modelo de preço (R$2.000 setup + R$1.000/mês)
- [ ] Continuar enviando 20–25 DMs/dia para novos dentistas
- [ ] **Critério para avançar:** pelo menos 1 dentista em conversa de preço

## Semana 4 (19–28 mai) — Fechar o 1º Cliente

**Objetivo:** Receber o primeiro pagamento.

- [ ] Para quem hesitar no preço: oferecer R$800 setup + R$700/mês em troca de depoimento em vídeo após 30 dias
- [ ] Criar contrato simples de 1 página (prestação de serviços + cláusula LGPD básica) — pode usar modelo do Jusbrasil
- [ ] Receber pagamento (PIX para familiar) antes de começar setup
- [ ] Enviar formulário de onboarding: procedimentos, preços, horários, nome dos dentistas, planos aceitos, frases que a IA deve usar
- [ ] Configurar agente com dados reais da clínica
- [ ] Testar internamente antes de ativar
- [ ] **Critério de sucesso do mês:** 1 cliente pagante com setup ativo

## Se Chegar na Semana 4 Sem Cliente

Não é fracasso — é dado. Antes de desistir ou mudar tudo:

1. Quantas DMs foram enviadas no total? Se < 200, o problema é volume, não oferta.
2. Qual foi a taxa de resposta? Se < 3%, o problema é a mensagem — testar outra abordagem.
3. Algum dentista pediu demo mas não fechou? Se sim, qual foi a objeção — preço, confiança, "vou pensar"?
4. Com base nas respostas acima, ajuste uma variável por semana. Não mude tudo ao mesmo tempo.
